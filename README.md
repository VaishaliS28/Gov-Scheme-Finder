
# Gov Scheme Finder

## About the Project
Gov Scheme Finder is a platform that helps users discover Indian government schemes based on their personal details and eligibility criteria.

It simplifies the process of finding suitable government schemes by providing information about eligibility, benefits, required documents, and application procedures.

**Goal:** To make government schemes easily accessible and understandable to everyone.

## 🛠️ Tech Stack
- Python
- FastAPI
- Streamlit
- Google Gemini AI
- LangChain
- ChromaDB
- Sentence Transformers
